# 片厂上手教程

> 这篇只讲"怎么用"；设计原因和架构在根目录 README。

## 0. 先配好钥匙

打开左侧轨道最下面的「API 设置」，两段：

1. **Agent 设置（DeepSeek 官方，默认）**
   - API Key：`sk-…`
   - Base URL：`https://api.deepseek.com/anthropic`
   - 模型名：`deepseek-flash`
   - 保存后**重启片场**才生效。
   - 想改用**火山方舟 v4.1（DeepSeek-V4.1-Flash）**：把 `plugin/filmflow.patch.yml` 里
     `agentProvider/agentModel` 与 `agent-default-model` 两处改成 `ark-volcengine` / `deepseek-v4-1-flash-261017`，
     再把 `ARK_LLM_API_KEY` 写进凭据文件 —— 它和出片用的 `ARK_API_KEY` **不是同一把**。
2. **AIGC 设置（火山引擎）**
   - 方舟 API Key：`ark-…` —— 视频（Seedance）/ 图片（Seedream）都走它。
   - 豆包语音 API Key：音频生成用；没有就留空。
   - 这两把**保存即生效**，不用重启。

> 语音 key 在「语音技术」控制台，不在方舟控制台。

## 1. 新建一部片

片库页 → 底部「新建片子」→ 填片名 → 选一套预设（悬疑 / 科幻 / 文艺 / 战争 / 奇幻 / 喜剧 / 短剧 / 电视剧 / 广告 / 纪录片 / MV / 企业宣传片）。

预设只是**起点**，建完照样能在画布上增删。现在默认骨架是：

```
事实层（人物 / 世界观 / 认知层…） → 剧本 → 分镜表 → 视频提示词
```

分镜表就是生成台：7 列（镜号 / 时长 / 景别 / 机位·运镜 / 画面内容 / 台词·声音 / 备注），每行末尾有「生成 / 预览」两格，
点镜号展开这一行的提示词。独立「生成视频」节点已经退场（老片里的仍可读可删）。

## 2. 画布怎么操作

- **滚轮**：上下滚动；**滚轮按下拖动**：平移画布（左键拖是选文字，故意的）。
- **点方块正文**：原地编辑，写完点外面保存。
- **人名节点**：单击标题直接改名（光标已聚焦、全选），回车即存；其它节点双击改名。
- **方块上的小按钮**：
  - `＋`：往下建节点（菜单只列这一步能建的；顶部有「自定义节点…」）
  - `↑ ↓`：同层移动
  - `✕`：删除（有下游依赖会拒绝，先改依赖）
- **表格节点**（分镜表）：每行尾有 ✕ 删行，表格下方「＋ 加一行」；这两格是虚拟列，不会写进 md。
- **顶栏**：刷新 / 撤销 / 重做 / ＋工序（项目顶层新建）/ 缩放 / **暂停**（agent 在跑时可打断）/ **会话历史**（切回旧会话）。
- **片库**：项目卡片右上角可「删除」—— 挪进同级 `_已删除/`，不硬删，删错能搬回来。
- **⚠ 过期**：上游改过，下游可能对不上 —— 让 agent 读了对齐，或自己点同步。

## 3. 和 agent 一起改片

右边是官方会话框。它只认这张图，不认聊天记录：

1. 你说需求，例如「把剧本里所有人物抽到人物节点里」；
2. agent 先看全片（`filmflow_board`），列出影响清单；
3. 改内容走**提案**：卡片上写清楚改什么、为什么，你点「确认」才落盘；
4. 上游改了 → 下游标过期 → agent 读、改、对齐，过期标记消失。

**方向规则**：上游改了下游，agent 可以直接改；下游要回头改上游，必须先问你。

**让它停**：顶栏「暂停」会真打断当前一轮；空闲时按会老实说"已经跑完了"。

## 4. 自定义一个节点

任何节点的 `＋` → 最上面「✎ 自定义节点…」：

1. agent 会先问一句「想建什么节点？」；
2. 你用自然语言说用途、读什么、写成什么格式（例如"表格三列：段落 / 观众反应 / 应对"）；
3. 它判断现有节点能不能复用；能复用会先建议；
4. 确认新建后，它把节点写进模板库（以后每部片都有），并在这一步下面挂一个实例。

节点模板存在 `%LOCALAPPDATA%\FilmFlow\user-templates.json`，删掉这个文件就回到出厂模板（49 个）。

## 5. 生成：分镜表 + 生成单元

1. **先分组**：分镜是剪辑单位，生成是素材单位。短于 4 秒的镜头**必须**和相邻镜并成一个「生成单元」
   （单镜生成 = 拿 4 秒换 1 秒）；4 秒以上的镜，同场景 + 同机位 + 连续动作也鼓励并。
   agent 会用 `filmflow_units` 读时长、出分组、校验后落到 `.film/units.json`；你也可以让它随时重分。
2. **写提示词**：点分镜表的镜号展开这一行的提示词（运镜·景别 / 画面 / 声音台词 / 时长汇总），可以手改，也可以让 agent 按模型规范写。
3. **生成**：点行/单元的「生成」；一个单元出**一条整片**（多镜一条连续镜头，中间没有剪辑点）。要拆镜用剪辑软件的自动分镜。
4. **预览与素材**：生成的图给缩略图、视频音频给 ▶/♪，点开全屏看；产物进「素材库」，按项目分文件夹。
5. **失败**：按报错查 Key / 模型开通 / 提示词是否为空；行状态记在 `.film/generation.json`，删行不删素材。

## 6. 参考资料

把用户原稿（剧本 docx、设定 txt、参考图…）放进片目录的 `参考/`，在画布上登记成参考节点。
**agent 对它是只读的**；参考一变，它会自动被叫醒，按流程跟下游：缺节点就提议新建、少人就提议改名、内容对不上就提议改正文。

## 7. 常见问题

**Q：改了剧本，为什么分镜没有自动变？**
A：不会自动改内容。上游改动只标"过期"，agent 读了下游再改（会先给你看影响清单/提案卡）。

**Q：节点下面为什么没有 ＋？**
A：这个节点是叶子（模型/生成/身份/剧情类），或者它的下位不在白名单里。用「＋ 工序」放到顶层，或换一个容器节点。

**Q：为什么短镜头不能单独生成？**
A：模型最短就是 4 秒。单独生成一个 1 秒镜头等于拿 4 秒换 1 秒，所以必须和相邻镜并成一个生成单元。

**Q：历史会话去哪了？**
A：顶栏「会话历史」列出当前 + 被换掉过的会话（带文件大小和最近写入时间），点「打开」切回并改绑。

**Q：数据在哪？备份怎么做？**
A：每部片在片库目录下，`.film/project.json` 是唯一声明，正文是 markdown；备份整个片库目录即可，`.film/backups/` 里还有改动前快照。
