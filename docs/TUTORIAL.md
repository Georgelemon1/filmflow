# 片厂上手教程

> 这篇只讲"怎么用"；设计原因和架构在根目录 README。

## 0. 先配好两把钥匙

打开左侧轨道最下面的「API 设置」，两段都要填：

1. **Agent 设置（DeepSeek）**
   - API Key：`sk-…`
   - Base URL：`https://api.deepseek.com/anthropic`
   - 模型名：`deepseek-flash`
   - 保存后**重启片场**才生效。
2. **AIGC 设置（火山引擎）**
   - 方舟 API Key：`ark-…` —— 视频（Seedance）/ 图片（Seedream）都走它。
   - 豆包语音 API Key：音频生成用；没有就留空。
   - 这两把**保存即生效**，不用重启。

> 两把 key 不是同一个控制台：方舟在「火山方舟 → API Key」，豆包语音在「语音技术」控制台。

## 1. 新建一部片

片库页 → 底部「新建片子」→ 填片名 → 选一套预设（悬疑 / 科幻 / 文艺 / 战争 / 奇幻 / 喜剧 / 短剧 / 电视剧 / 广告 / 纪录片 / MV / 企业宣传片）。

预设只是**起点**，建完照样能在画布上增删。标准五道工序是：

```
事实层 → 剧本 → 分镜脚本 → 视频提示词 → 生成视频
（音频片多一步：音频提示词 → 音频节点）
```

## 2. 画布怎么操作

- **滚轮**：上下滚动；**滚轮按下拖动**：平移画布（左键拖是选文字，故意的）。
- **点方块正文**：原地编辑，写完点外面保存。
- **方块上的小按钮**：
  - `＋`：往下建节点（菜单只列这一步能建的；顶部有「自定义节点…」）
  - `↑ ↓`：同层移动
  - `✕`：删除（有下游依赖会拒绝，先改依赖）
- **顶部控制条**：刷新 / 撤销 / 重做 / ＋工序（在项目顶层新建）/ 缩放。
- **⚠ 过期**：上游改过，下游可能对不上 —— 让 agent 读了对齐，或自己点同步。

## 3. 和 agent 一起改片

右边是官方会话框。它只认这张图，不认聊天记录：

1. 你说需求，例如「把剧本里所有人物抽到人物节点里」；
2. agent 先看全片（`filmflow_board`），列出影响清单；
3. 改内容走**提案**：卡片上写清楚改什么、为什么，你点「确认」才落盘；
4. 上游改了 → 下游标过期 → agent 读、改、对齐，过期标记消失。

**方向规则**：上游改了下游，agent 可以直接改；下游要回头改上游，必须先问你。

## 4. 自定义一个节点

任何节点的 `＋` → 最上面「✎ 自定义节点…」：

1. agent 会先问一句「想建什么节点？」；
2. 你用自然语言说用途、读什么、写成什么格式（例如"表格三列：段落 / 观众反应 / 应对"）；
3. 它判断现有节点能不能复用；能复用会先建议；
4. 确认新建后，它把节点写进模板库（以后每部片都有），并在这一步下面挂一个实例。

节点模板存在 `%LOCALAPPDATA%\FilmFlow\user-templates.json`，删掉这个文件就回到出厂模板（53 个）。

## 5. 生成图片 / 视频 / 音频

1. 在「视频提示词 / 音频提示词」下建模型节点（视频模型 / 图片模型 / 音频模型），选具体模型；
2. 生成节点（生成视频 / 图片节点 / 音频节点）上写提示词，或让 agent 按上游写好；
3. 点生成 → 产物进「素材库」，按项目分文件夹；
4. 失败时按报错检查：Key 对不对、模型开没开通、提示词是否为空。

> 视频/图片走方舟，音频走豆包语音 —— 音频的 Key 与方舟不是同一把。

## 6. 常见问题

**Q：改了剧本，为什么分镜没有自动变？**
A：不会自动改内容。上游改动只标"过期"，需要 agent 读了下游再改（它会先给你看影响清单）。

**Q：节点下面为什么没有 ＋？**
A：这个节点是叶子（模型/生成/身份/剧情类），或者它的下位不在白名单里。用「＋ 工序」放到顶层，或换一个容器节点。

**Q：能不能不用 agent，全手动？**
A：可以。画布能建、删、改名、编辑正文；agent 只是帮你改内容、写提示词、对齐过期。

**Q：数据在哪？**
A：每部片在片库目录下，`.film/project.json` 是唯一声明；正文是 markdown。换机器把片库目录拷走即可。

**Q：怎么备份？**
A：备份整个片库目录；`.film/backups/` 里还有每次结构/正文改动前的快照。
