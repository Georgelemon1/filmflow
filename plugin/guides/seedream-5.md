# Seedream 5.0 系列提示词写法（pro / lite / flash）

> 来源：火山方舟官方《Seedream 4.0–5.0 提示词指南》《Seedream 5.0 pro 交互编辑指南》与本仓库 `docs/提示词-按模型规范.md` §三。2026-10-28 整理。

## 五条通用规则
1. **自然语言写清 主体 + 行为 + 环境**，美学（风格/色彩/光影/构图）用自然语言或短语补充。
   - ✅「一个穿着华丽服装的女孩，撑着遮阳伞走在林荫道上，莫奈油画风格」
   - ❌「一个女孩，撑伞，林荫街道，油画般的细腻笔触」
2. **写明应用场景/用途**：`设计一个游戏公司的 logo，主体是…，logo 上写有 "PITBULL"`。
3. **风格要精准**：用准确风格词，或直接给参考图。
4. **要渲染的文字放双引号**：`标题为 "Doubao Seedream 4.5"`。
5. **编辑要指明对象 + 保持不变的部分**，禁用模糊代词。
   - ✅「让图中最高的那只熊猫穿上粉色京剧服饰并戴上头饰，**并保持动作不变**」
   - ❌「让它穿上粉色衣服」

## 一条反直觉的结论（对本项目最有用）
> 官方原话：这代模型理解力强、画面不再泛白，所以**简洁精确优于堆叠华丽词**。

「手绘动漫风格」会把模型拉去插画质感；要写实就换成写实的风格词。

## 多图与组图
- 多图输入：`将图一的主体替换为图二的主体` / `让图一人物穿上图二的服装` / `参考图二的风格，对图一进行风格转换`。
- 组图：用「一系列 / 一套 / 组图」触发，或直接写数量（`生成四张图，影视分镜，分别对应…`）。
- 复杂画面可用箭头/线框/涂鸦标注编辑区域（本项目暂未接）。

## 参数
- 分辨率档位：pro 1K/2K/3K/4K；lite 1K/2K/4K；flash 1K/2K/4K。
- **比例与分辨率写进参数面板**，不写进提示词正文（图片比例由片场自动追加）。

## 片场硬规矩
- 图片提示词短而准，不要堆形容词。
- 要文字就加双引号；文字多或拼写重要时，做成参考图传进去。
- 与视频提示词分开写：图片模型不认 Seedance 的镜头/时间戳写法。
