# Seedance 2.5 提示词写法（片场速查）

> 来源：火山方舟官方《Seedance 2.5 提示词指南》与本仓库 `docs/提示词-按模型规范.md` §二、`docs/sd25-pe-SKILL.md`。2026-10-28 整理。

## 硬指标
- 单段 **30 秒**直出；单次最多 50 个参考素材。
- 素材上限：图片 ≤30 张（4K 内）、视频 ≤10 段总时长 ≤30s、音频 ≤10 段总时长 ≤30s。
- 主体数量 1–5 最稳；多宫格分镜 ≤15 格（线稿/火柴人最稳）。

## 两类任务，写法不同
- **有锁定**（编辑 / 首尾帧 / 延长）：参数 `ratio=adaptive`、编辑时 `duration=-1`、建议 mov；
  靠 `role=reference_image/reference_video/reference_audio` + 提示词关键词（编辑/增加/删除/修改/替换/延长/续写）触发。
- **无锁定**（参考类 / 多宫格 / 关键帧）：可自定义宽高比与时长。

## 提示词四段结构
1. **素材指代**：每个图/视频/音频编号 + 用途（谁是形象、谁是音色、谁是动作、谁是场景）。
2. **一句话概述**：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜。
3. **具体情节**：用整数秒时间戳或「镜头 N」切分，逐段写画面/运镜/动作/台词/音效；尽量正向描述。
4. **结尾**：贯穿细节（机位、环境、声音、氛围）。

基础生成模板：
```text
<主体>在<场景与环境>中<主要动作或事件>。
画面呈现<视觉风格或情绪>。
镜头采用<景别、机位、运镜或切镜>。
声音包括<对白、环境声、音效或音乐>。
```

## 时间戳规则
- 单位 1 秒，支持区间 `0-3s`、时间点 `第 5s`、相对时间 `3 秒后`。
- 时间轴要**连续**，不要 `0-3s … 5-6s` 跳空。
- 不要用时间戳控频次（如「一秒摇头 3 次」）。

## 负向控制（官方支持）
- 字幕：`不要字幕` / `不额外加入对白字幕`。
- 声音可拆分：`无 bgm，只生成环境音和动作音` / `不要任何声音`。
- BGM 管不住：穷举同义词（音乐/背景音乐/BGM/配乐/器乐/旋律/合成器/氛围铺底），首尾各写一遍。

## 镜头语言
- 通识词可直写：景别（大全景/中景/近景/特写）、运镜（推拉摇移跟/环绕/俯冲/后拉/手持）、机位（低角度/俯视/第一人称）。
- 热门运镜可直写：一镜到底、希区柯克变焦、航拍、FPV、子弹时间。
- 小众词要转成「名词 + 描述性解释」；转场写清触发点 + 时间 + 方式。

## 与 2.0 的四个差异
1. 2.5 认**整数秒时间戳**；2.0 只认镜头序号。
2. 2.5 支持多视图主体参考；2.0 不建议。
3. 2.5 支持 0.4–2.5 任意宽高比；2.0 只有 6 档。
4. 2.5 支持 MOV 输出（编辑/延长一致性更好）。

## 官方 FAQ 最实用的四条
| 现象 | 解法 |
|---|---|
| 人物眼睛发光（情绪过度） | 最高优先级写「人物为正常人眼、不发光」；「狂热」改成「惊叹」 |
| 角色对应错位 | 按人物首次出场顺序上传参考素材，同步调整编号 |
| 文字拼错 | 英文拆字母按序出现；中文把正确文案做成参考图传进去 |
| 字幕/BGM 约束不生效 | 字幕：避免台词后复述+加语气/表情；BGM：穷举同义词+首尾重复 |

## 片场硬规矩
- 画幅/时长/分辨率/帧率/声音开关**不写进正文**（参数面板负责）。
- 模型不同不要套同一段提示词；2.5 不要自动加画质包/稳定包/水印/字幕。
- 默认只给一个最优 Prompt，用户明确要对比才给多个。
