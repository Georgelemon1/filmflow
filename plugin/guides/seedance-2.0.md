# Seedance 2.0 系列提示词写法（2.0 / fast / mini 通用）

> 来源：火山方舟官方《Seedance 2.0 系列提示词指南》与本仓库 `docs/提示词-按模型规范.md` §一、`docs/sd2-pe-SKILL.md`。2026-10-28 整理。

## 模型定性
「全模态 AI 导演」：同时读文字/图/视频/音频，内部拆成**空间层**（画面里有什么）与**时间层**（如何变化）。

## 文生视频进阶公式
```text
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

## 任务句式
| 任务 | 句式 |
|---|---|
| 全模态参考 | `参考<图片N>中的<主体N>，生成…`；`参考<视频N>中的<动作/运镜/风格/音效>，生成…`；`参考<音频N>中的音色，生成…` |
| 编辑视频 | 增加：`<元素特征> + <出现时机> + <出现位置>`；修改：`严格编辑<视频N>，将其中的<原特征>修改为<新特征>`；删除：点明删什么**并强调保持不变的部分** |
| 延长视频 | `向前/向后延长<视频N>，生成…`；轨道补全：`<视频1> + <过渡画面> + 接 <视频2>` |

⚠ 编辑/延长写 `"<视频N>"`，**别写「参考<视频N>」**（会被误判成参考任务）。

## 主体定义（多素材必做）
- 句式：`将<图片/视频N>中的[主体核心特征]定义为<主体N>`。
- 核心特征 = 2–3 个稳定静态特征（服饰/发型/外观/类别）。
- 每次提及带标签：未定义用 `<主体N>@<图片N>`，已定义沿用同一标签。
- **Asset ID 不能替代 `<图片N>`**（模型不认 ID）。

## 2.0 的硬约束
- **不要写时间戳**（只认镜头序号）；要分镜就写「镜头 1 / 镜头 2」。
- **一镜一运镜**：单镜头只许 1 种运镜，禁止推拉摇移叠加。
- 强制挂「画质包 + 稳定包 + 水印/Logo 兜底」，再按场景加字幕/双胞胎兜底。
- 人脸参考：大头照 + 全身照；**禁用三视图/多视图**。
- 引用语法 `@图片N` / `@视频N` / `@音频N`；严禁裸写 `[asset-xxx]`；`@图片N` 后紧跟动词/方位词要加隔断（`张红@图片1` 或 `@图片1 中的女子`）。

## 音频通道
- 对白/环境声/音效/音乐分开写；模型自带音频时仍要写清「声音包括…」。
- 不想要音乐就明确写「无 bgm」，与 2.5 一样可以分维度控制。

## 片场硬规矩
- 画幅/时长/分辨率不写进正文（参数面板负责）。
- 2.0 与 2.5 美学差异明显，**不要混用同一段提示词**。
- 写之前先确认这部片的「视频模型」节点选的是 2.0 系列还是 2.5。
