# Seedream 4.5 / 4.0 提示词写法

> 来源：火山方舟《Seedream 4.0–5.0 提示词指南》与本仓库 `docs/提示词-按模型规范.md` §三。2026-10-28 整理。

规则与 Seedream 5 系列基本一致，差别只在档位与细节：

- **分辨率档位**：4.5 → 2K/4K；4.0 → 1K/2K/4K。比例/分辨率进参数面板，不写正文。
- **主体 + 行为 + 环境**用自然语言写清楚；风格词要准，或给参考图。
- **文字**：要渲染的文字放双引号；大段文字建议做成参考图。
- **编辑**：指明对象 + 强调不变的部分（`保持动作不变`），禁用「它/这个」这类模糊指代。
- **多图**：`将图一的主体替换为图二的主体` / `参考图二的风格，对图一进行风格转换`。
- **组图**：用「一系列 / 一套 / 组图」或直接写数量。

## 片场硬规矩
- 简洁精确优先，不要堆「电影级/超高清/8K/杰作」这类空词。
- 图片模型不认 Seedance 的镜头/时间戳写法；不要把视频提示词直接粘过来。
