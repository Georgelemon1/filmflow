## 一、通用规则（五条）

1. **用自然语言清晰描述画面**
   用**简洁连贯**的自然语言写清 **主体 + 行为 + 环境**；对美学有要求时，用自然语言或短语补充 **风格 / 色彩 / 光影 / 构图**。
   - ✅ `一个穿着华丽服装的女孩，撑着遮阳伞走在林荫道上，莫奈油画风格。`
   - ❌ `一个女孩，撑伞，林荫街道，油画般的细腻笔触。`（堆词、不成句）

2. **写明应用场景和用途**
   - ✅ `设计一个游戏公司的 logo，主体是一只在用游戏手柄打游戏的狗，logo 上写有公司名 "PITBULL"。`
   - ❌ `一张抽象图片，狗拿着游戏手柄，狗狗上写 PITBULL。`

3. **风格要精准**：用准确的**风格词**，或直接给**参考图**（参考图比形容词可靠）。

4. **画面里的文字用双引号**：`生成一张海报，标题为 "Doubao Seedream 4.5"`（不加引号容易被改写）。

5. **编辑类要写清「改什么 + 什么不变」**，别用模糊代词。
   - ✅ `让图中最高的那只熊猫穿上粉色的京剧服饰并戴上头饰，并保持动作不变。`
   - ❌ `让它穿上粉色衣服。`

## 二、文生图

- **简洁精确 > 堆砌华丽词**。5.0 lite / 4.5 / 4.0 理解力强，少描述也能出；画面不再泛白，重复堆词反而变差。
- **细节多就逐项写清**（示例：凌乱办公桌，桌面有开着的笔记本、写着 "Developer" 的马克杯、摊开的维恩图书、思维导图便签、掉帽的钢笔、显示通知的手机、角落多肉；背景是虚化书架；阳光从右侧照射）。
- **专业知识/图表要写清术语与形式**：`在黑板上画出下列二元一次方程组及其相应的解法步骤：5x + 2y = 26；2x - y = 5。` / `绘制一张信息图，展示通货膨胀的成因，每条成因独立呈现，并配有简洁图标。`

## 三、图生图：编辑（增 / 删 / 替 / 改）

用简洁明确的文字**准确指示对象与变化**：

| 操作 | 官方示例 |
|---|---|
| 增加 | `给图中女生增加相同款式的银色耳线和项链。` |
| 删除 | `去掉女生的帽子。` |
| 替换 | `把最大的面包人换成牛角包形象，保持动作和表情不变。` |
| 修改 | `让图中三个机器人变成透明水晶材质，颜色从左到右分别变成红黄绿。并让绿色的机器人跑起来，黄色的走路，红色的站立。` |

**复杂画面用视觉信号指位**：箭头 / 线框 / 涂鸦直接在图上标，提示词里说"红色涂抹位置""红框大小"。
- `将房间内红色涂抹位置放入电视，蓝色涂抹位置放入沙发，不改变其他布局，确保放入物体和整张图的原木风格一致。`
- `放大图中的标题至红框大小，并改成和萨克斯图案一样的颜色和字体风格。`

## 四、图生图：参考图

提示词里**只写两件事**：

1. **指明参考对象**：想从参考图里提取并保留什么（人物形象 / 材质 / 风格 / 款式）。
2. **描述生成画面**：要生成的场景、构图、内容。

示例：
- 参考人物形象：`参考图中的人物形象，做一个动漫人物手办，放在桌上……生成尺寸和现在图一样；手办在图片的左边；整个图片的风格和原始图一样，大片摄影感。`
- 参考风格：`参考图标的线性简约风格，设计9个不同场景下的应用 icon，包括：音乐、天气……保持一致的配色。`
- 参考款式：`生成四件不同材质和颜色的上衣，衣服款式与图中女生身上的衣服一致，只要衣服，不要模特。`

**草图/线稿 → 高保真**三步：
1. 提供清晰原图；图里有文字就注明"遵循图中文字内容进行生成"。
2. 明确主体与要求（高保真 UI / 现代简约客厅实景图）。
3. 指出必须与参考图一致的关键点（家具位置、原型布局、空间方向）。

---

## 五、多图输入（替换 / 组合 / 迁移）

**逐图点名职责**，不要含糊：
- `将图一的主体替换为图二的主体。`
- `让图一人物穿上图二的服装。`
- `参考图二的风格，对图一进行风格转换。`

⚠️ 片场对应：多图参考就是 `@图片N`。每份素材一行职责，别写成"参考这几张图"的范围句。

---

## 六、多图输出（组图 / 分镜序列）

- 用「一系列 / 一套 / 组图」触发组图，或用**具体数字**：`生成四张图，影视分镜，分别对应：宇航员在空间站维修飞船、突然遇到陨石带袭击、宇航员紧急躲避、受伤后惊险逃回飞船。`
- 适合：分镜、漫画、成套 IP 设计、表情包；要求**角色连贯、风格统一**时在提示词里写明这一点。

## 八、片场规矩（这条最重要）

1. **画幅 / 尺寸 / 水印 / 输出格式不进正文** —— 那是参数，走画布参数面板或 `filmflow_set_media`。
2. **不自动加**画质包、稳定包、"高清细节丰富"这类通用形容词（除非用户要求）—— 官方自己也说"简洁精确优于堆砌"。
3. **分镜转图**（把某一镜画成首帧/参考图）时：写这一镜的**主体 + 动作 + 场景 + 光影**，再用 `画风` 列那句统一风格；不要整段分镜文本直接粘过去。
4. **角色/场景参考图**：用「参考图中的人物形象」「参考场景的空间布局」这类**职责句**，别只说"参考这张图"。
5. **画面里要出字**：中文容易错字，官方建议把正确文案做成参考图传进去；数字/英文可拆字母按序出现。
6. 一次只给**一个最佳版本**，用户明确要对比才给多个。

## 九、执行通道与硬限制（官方 AgentPlan skill v5.2.6 摘录）

> 来源：`byted-ark-seedream-skill` v5.2.6（`volcengine/agentplan`，MIT，2026-11-04 安装，23 个文件）。
> 它是**执行器 skill**（跑 `node scripts/generate.js` 直连 AgentPlan 订阅通道），不是提示词规范；片厂 agent 没有命令行，跑不了它的脚本，所以这里只取事实。

### 9.1 两条通道不一样

| 通道 | 地址 | 谁在用 |
|---|---|---|
| AgentPlan 订阅 | `https://ark.cn-beijing.volces.com/api/plan/v3/images/generations` | 官方 skill 的脚本 |
| 后付费 API | `https://ark.cn-beijing.volces.com/api/v3/images/generations` | **片厂**（宿主媒体层） |

两条通道的能力/限额不同 —— 官方 skill 里写的"组图 / 联网 / 流式 / 3K·4K / 超 10 张参考图 内置不支持"是**订阅通道**的限制，片厂走的后付费通道 **4K 是支持的**，别照搬。

### 9.2 Lite 已下线

官方在请求前直接拒绝：`lite`、`doubao-seedream-5.0-lite`、`doubao-seedream-5-0-lite` 以及日期版 Lite ID，提示迁移到 **Flash / Pro**。
片厂里 `doubao-seedream-5-0-260128` 已标「已下线」；`空白1` 的「图片模型」选项同步改了标签。

### 9.3 参数规则（订阅通道，供参考）

- 参考图：普通生成最多 **10 张**；图层拆分 / 透明编辑**恰好 1 张**（透明编辑要真带 alpha 的图）。
- `optimize_prompt_mode: fast`（服务端极速提示词优化）**仅 Pro**；`auto` 会选 Pro。
- `background: transparent` 只在透明编辑时用。
- `output_format`：png/jpeg；拆图层只控制底图，其他图层固定 PNG。
- `count` 内置只接受 1；组图数量由**提示词**引导（"生成四张…"），不是靠 count。
- 图层拆分返回的多张图层**不是**连贯组图。
- 脚本只做"结构化参数 + 少量画质关键词兜底"；自然语言理解与否定语义由 agent 负责 —— 所以提示词该写清就写清。

### 9.4 它里面唯一和提示词有关的东西（其余都是参数/脚本）

这份 skill **没有提示词规范**（结构、风格、负向控制一条都没有），它只有下面几条"写法约定"，来自 `references/EXAMPLES.md`：

- **编辑类**要写"改什么 + 其余保持不变"：`在蓝色框内添加电视机，移除蓝框，保持其余布局不变`。
- **交互编辑（interactive_edit）用 bbox 坐标标签定位对象**：
  `将图1<bbox>179 283 796 986</bbox>的主体放到图2<bbox>118 331 933 871</bbox>位置`
  —— 坐标是 0~999 归一化值（官方 5.0 pro 编辑指南口径），且**必须来自用户给的定位信息，不许猜**。
- **图层拆分**可以不给 prompt（自动全拆），也可以点名：`拆出人物、标题文字和右下角装饰图标`。
- **透明编辑**要在 prompt 里强调保持透明背景：`将鹦鹉改为孔雀，保持透明背景`；输入图必须真带 alpha。
- **服务端提示词优化**是参数 `--optimize_prompt_mode fast`（仅 Pro），与本地 `optimize` 独立；别把它当 prompt 内容。
- **从 Lite 迁移**时，不只是换模型名：要移除组图、流式、联网、`reference_strength`，分辨率降到支持档位，普通参考图 ≤10 张。
