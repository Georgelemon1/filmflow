## 一、Seedance 2.0 系列（视频）

官方定性：**"全模态 AI 导演"** —— 同时读文字/图/视频/音频，内部拆成**空间层**（画面里有什么）
和**时间层**（事情如何随时间变化）。

### 基础公式（按任务类型）

| 任务 | 官方句式 |
|---|---|
| 全模态参考 | `参考<图片N>中的<主体N>，生成…` / `参考<视频N>中的<动作/运镜/风格/音效>，生成…` / `参考<音频N>中的音色，生成…` |
| 编辑视频 | 增加：`<元素特征> + <出现时机> + <出现位置>`；修改：`严格编辑<视频N>，将其中的<原特征>修改为<新特征>`；删除：点明删什么，**并强调保持不变的部分** |
| 延长视频 | `向前/向后延长<视频N>，生成…`；轨道补全：`<视频1> + <过渡画面> + 接 <视频2>` |

⚠ 编辑/延长写 `"<视频N>"`，**别写"参考<视频N>"**（会被误判成参考任务）。

### 进阶公式（文生视频）

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

### 主体定义（多素材/多主体必做）

- 句式：`将<图片/视频N>中的[主体核心特征]定义为<主体N>`
- 核心特征 = **2–3 个稳定静态特征**（服饰/发型/外观/类别）
- 每次提及都要带标签：未定义用 `<主体N>@<图片N>`，已定义沿用同一标签
- **Asset ID 不能替代 `<图片N>`**（模型不认 ID）

## 二、Seedance 2.5（视频，与 2.0 差异很大）

### 硬指标
- 单段 **30 秒**直出；单次最多 **50 个参考素材**
- 素材上限：图片 ≤30 张（4K 内）｜视频 ≤10 段、总时长 ≤30s｜音频 ≤10 段、总时长 ≤30s
- 主体数量：图 **1–5** 最稳；音视频主体 **1–5**，5–10s 时长最稳
- 多宫格分镜 **≤15 格**，推荐线稿/火柴人；白模推荐**粗粒度**

### 两类任务（2.0 没有这个区分）
- **有锁定**（编辑 / 首尾帧 / 延长）：`ratio` 必须 `adaptive`，编辑任务 `duration` 必须 `-1`，
  输出格式建议 **mov**；编辑靠 `content.role = reference_image/reference_video/reference_audio`
  + 提示词关键词（编辑视频/增加/删除/修改/替换/延长/续写）触发
- **无锁定**（参考类 / 多宫格 / 关键帧）：可自定义宽高比与时长

### 提示词结构（四段）
1. **素材指代**：每个图/视频/音频编号 + 用途（谁是形象、谁是音色、谁是动作、谁是场景）
2. **一句话概述**：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜
3. **具体情节描述**：用时间戳或「镜头 N」切分，逐段写画面/运镜/动作/台词/音效，尽量正向描述
4. **结尾**：贯穿细节（机位/运镜、环境、声音、氛围）

### 时间戳规则
- 单位 **1 秒**，支持区间 `0-3s`、时间点 `第 5s`、相对时间 `3 秒后`
- **时间轴要连续**（别写 `0-3s … 5-6s`）
- 区间给太少 → 模型自由发挥；给太多 → 过度剪切/遗漏
- **不要用时间戳控频次**（如"一秒摇头 3 次"）

### 负向控制（官方支持）
- 字幕：`不要字幕` / `不额外加入对白字幕`
- 音频可分维度：`无 bgm，只生成环境音和动作音` / `不要任何声音`
- BGM 管不住时：**穷举同义词**（音乐/背景音乐/BGM/配乐/器乐/旋律/合成器/氛围铺底）+ **首尾各写一遍**

### 镜头语言
- 通识词可直写：景别（大全景/中景/近景/特写）、运镜（推拉摇移跟/环绕/俯冲/后拉/手持）、机位（低角度/俯视/第一人称）
- 热门运镜可直写：一镜到底、希区柯克变焦、航拍、FPV、子弹时间
- **小众词要转成「名词 + 描述性解释」**
- 转场写清**触发点 + 时间 + 方式**（如"第 5s 快速向左横移转场（擦除+叠化）"）

### 与 2.0 的四个差异
1. 2.5 **响应整数秒时间戳**；2.0 只认镜头序号
2. 2.5 支持**多视图**主体参考（2.0 不建议）
3. 2.5 支持 **[0.4, 2.5] 任意宽高比**（2.0 只有 6 档）
4. 2.5 支持 **MOV 输出**，延长/编辑时色彩与声画一致性更好

### 官方 FAQ 里最实用的四条
| 现象 | 解法 |
|---|---|
| 人物**眼睛发光**（情绪过度响应） | 提示词最高优先级写"人物为正常人眼、不发光"；把"狂热/极度震惊"改成"惊叹" |
| 角色对应错位 | **按人物首次出场顺序**上传参考素材，并同步调整编号 |
| 文字拼写错 | 英文拆成单个字母按序出现；中文把正确文案**做成参考图**传进去 |
| 字幕/ BGM 约束不生效 | 字幕：避免在台词后复述词语+加语气/表情；BGM：穷举同义词 + 首尾重复 |

## 三、Seedream 4.0–5.0（图片）

### 五条通用规则
1. **自然语言写清 主体 + 行为 + 环境**，美学（风格/色彩/光影/构图）用自然语言或短语补充
   - ✅「一个穿着华丽服装的女孩，撑着遮阳伞走在林荫道上，莫奈油画风格」
   - ❌「一个女孩，撑伞，林荫街道，油画般的细腻笔触」
2. **写明应用场景/用途**：`设计一个游戏公司的 logo，主体是…，logo 上写有 "PITBULL"`
3. **风格要精准**：用准确风格词，或直接给**参考图**
4. **要渲染的文字放双引号**：`标题为 "Doubao Seedream 4.5"`
5. **编辑要指明对象 + 保持不变的部分**，禁用模糊代词
   - ✅「让图中最高的那只熊猫穿上粉色京剧服饰并戴上头饰，**并保持动作不变**」
   - ❌「让它穿上粉色衣服」

### 一条反直觉的结论（对我们最有用）
> 官方原话：这代模型理解力强、**画面不再泛白**，所以**简洁精确优于堆叠华丽词**。

我们之前写"赛博朋克手绘动漫风格，一个巨大的图书馆内部，半空中全景拍摄"就是简洁型，方向是对的；
但**"手绘动漫风格"会把模型拉去插画质感** —— 要写实就得改风格词。

### 多图与组图
- 多图输入：`将图一的主体替换为图二的主体` / `让图一人物穿上图二的服装` / `参考图二的风格，对图一进行风格转换`
- 组图：用「一系列 / 一套 / 组图」触发，或直接写数量（`生成四张图，影视分镜，分别对应…`）
- 复杂画面难描述时，可用**箭头/线框/涂鸦**在图上标注编辑区域（我们暂未接）

## 四、片场执行规则（写进 agent 的硬规矩）

1. **视频按 Seedance 公式检查**：主体 / 动作 / 场景 / 光影 / 运镜 / 风格 / 画质 / 约束 —— 缺哪项在提案里说清
2. **2.5 的时长与时间戳对齐**：单段 ≤30s；用整数秒时间轴，且时间轴连续
3. **2.0 不写时间戳**（它只认镜头序号），要分镜就写「镜头 1 / 镜头 2」
4. **图片写简洁**：主体+行为+环境+风格，别堆形容词；要文字就加双引号、必要时做成参考图
5. **模型不同不要套同一段提示词**：2.0/2.5 美学差异明显（官方 FAQ 确认），混用会风格不连续
6. **`<图片N>` 不许写成 Asset ID**
7. 比例/分辨率/时长写进**参数**，不写进正文（图片比例例外，由片场自动追加）

## 四之二、sd2-pe（Seedance 2.0）与 sd25-pe 的**硬冲突**（谁也别混用）

| 项 | sd2-pe（2.0） | sd25-pe（2.5） |
|---|---|---|
| 时间控制 | **镜头顺序优先**：写 `镜头1/镜头2`，**不要写 `0–3s`** | **认整数秒时间戳**（`0-3s`），且时间轴要连续 |
| 兜底约束 | **强制挂**：画质包 + 稳定包 + 水印/Logo 兜底（再按场景加字幕/双胞胎兜底） | **禁止滥加**：不许自动加画质包/稳定包/水印/字幕 |
| 运镜 | **一镜一运镜**：单镜头只许 1 种运镜，禁止推拉摇移叠加 | 无此硬限 |
| 人脸 | **大头照 + 全身照**，**禁用三视图/多视图** | 支持多视图主体参考 |

sd2-pe 另外三条：`@图片N/@视频N/@音频N` 编号引用；**严禁 `[asset-xxx]` 裸写**；
`@图片N` 后面紧跟动词/方位词要加隔断（写 `张红@图片1` 或 `@图片1 中的女子`）。

### sd25-pe 的 11 条硬原则（节选最关键 6 条）

1. **意图优先**：不得改变人物身份/数量、关键道具、场景、事件因果、空间关系、编辑对象、延长方向、故事结果
2. **模板优先**：无论原 Prompt 多完整，都要套模板重组，**不能只做同义改写**
3. **素材逐份负责**：每份素材说明用途；可用但未分配的素材要逐个列入 `【未采用素材】`，防止后续被重新激活
4. **参数分离**：画幅/时长/分辨率/帧率/声音开关**不写进 Prompt**（片场已有的参数面板就是干这个的）
5. **不滥加约束**：不自动加画质包/稳定包/水印/字幕/分身等用户没要求的负向约束
6. **单一最佳版本**：默认只给一个最优 Prompt，用户明确要对比才给多个

### 基础生成模板（sd25-pe 原文）

```text
<主体>在<场景与环境>中<主要动作或事件>。
画面呈现<视觉风格或情绪>。
镜头采用<景别、机位、运镜或切镜>。
声音包括<对白、环境声、音效或音乐>。
```

### Seedance 2.5 直连参数（来自官方 quickstart 包，2026-10-23）

```
base_url  https://ark.cn-beijing.volces.com/api/v3
model     doubao-seedance-2-5-260628
提交      client.content_generation.tasks.create(
            model, content=[
              {type:"text", text:...},
              {type:"image_url", image_url:{url}, role:"reference_image"},
              {type:"video_url", video_url:{url}, role:"reference_video"},
              {type:"audio_url", audio_url:{url}, role:"reference_audio"},
            ],
            generate_audio=True, ratio="adaptive", duration=-1, watermark=True)
轮询      tasks.get(task_id) → status: succeeded/failed/其他; 成功取 content.video_url
```

> 注意最后那个 `watermark=True` —— 直连 Ark 时**水印是显式参数**，可以设 False；
> 小云雀那层没暴露，这也是"当模型 API 用"必须直连的原因之一。
